# SQL
Ce projet a pour objectif de mettre en pratique mes compétences en SQL à travers différents use cases business et problématiques d’analyse de données.

Les données utilisées proviennent principalement de Kaggle. Selon les cas d’usage, différentes technologies de stockage et bases de données pourront être utilisées, notamment BigQuery, Snowflake ou d’autres systèmes de gestion de bases de données.

L’objectif est de développer une approche orientée Data Analysis et Business Intelligence, en utilisant SQL pour :

- explorer et comprendre les données ;
- nettoyer et transformer les données ;
- construire des indicateurs et métriques business ;
- répondre à des problématiques métier ;
- extraire des insights pertinents à partir des données.

Ce repository permet ainsi de pratiquer le SQL dans différents environnements et sur des problématiques business variées.
